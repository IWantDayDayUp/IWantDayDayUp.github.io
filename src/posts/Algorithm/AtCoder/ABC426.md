## 📌 C - Upgrade Required{#C}

![426C]()

::: tip
Let us consider what happens when PCs with version $X$ or prior is upgraded to version $Y$:

- Let $O$ be the oldest among the current versions. Then all PCs with versions between $O$ and $X$ will be upgraded
- Since the constraints guarantee $X < Y$, as a result of this upgrade, there will no longer be a PC of version $X$ or prior. For the later upgrades, $O$ is always $X + 1$ or greater

:::

::: Info
Thus, we obtain the following solution:

- First, the oldest version is $O = 1$
- For $i = 1, 2, ..., Q$ in order, perform the $i$-th operation
  - If $X_i < O$, there is no PC with version $X_i$ or prior, so skip this operation
  - Otherwise, repeat the following while $O
  - le X_i$:
    - Upgrade all PCs with version $O$ to $Y_i$
    - Then, let $O \rightarrow O + 1$

:::

```cpp
// Basic version
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;

    vector<int> cnt(N, 1);
    int o = 0;

    while (Q--)
    {
        int X, Y;
        cin >> X >> Y;
        X--;
        Y--;

        int ans = 0;
        while (o <= X)
        {
            ans += cnt[o];
            cnt[Y] += cnt[o];
            o += 1;
        }

        cout << ans << endl;
    }

    return 0;
}
```

```cpp
// DSU Jump version

#include <bits/stdc++.h>

using namespace std;

struct DSUJump
{
    vector<int> f;

    DSUJump() {}
    DSUJump(int n) { init(n); }

    void init(int n)
    {
        f.resize(n + 1);
        iota(f.begin(), f.end(), 0);
    }

    int find(int x)
    {
        while (x != f[x])
        {
            x = f[x] = f[f[x]];
        }
        return x;
    }

    inline void erase(int x)
    {
        f[x] = find(x + 1);
    }
};

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;

    vector<long long> cnt(N + 2, 0);
    for (int i = 0; i < N; i++)
    {
        cnt[i] = 1;
    }

    DSUJump dsu(N);

    while (Q--)
    {
        int X, Y;
        cin >> X >> Y;
        X--;
        Y--;

        long long ans = 0;

        int j = dsu.find(0);
        while (j <= X)
        {
            ans += cnt[j];
            cnt[Y] += cnt[j];
            cnt[j] = 0;

            dsu.erase(j);
            j = dsu.find(j);
        }
        cout << ans << endl;
    }

    return 0;
}
```

## 📌 D - Pop and Insert{#D}

![426D]()

::: tip
Let us consider the minimum number of operations required to make all digits `0`. (Same discussions apply to making all `1`)
:::

::: tip
First of all, we need to perform at least one operation against each digit that was originally `1`.

> Performing an operation against a digit means removing one digit, flip it, and insert it back

For each digit that was originally `0`, we need to perform an even number of operation of operations, so we either apply zero operations, or two or more operations.
:::

::: tip
Let us try to maximize the number of digits that was originally `0` for which we do not apply an operation.

If we do not perform an operation against digits initially positioned at $i$-th and $j$-th($i < j$), we cannot perform an operation against any digit between them $(i + 1)$-th through $(j - 1)$-th. Thus, the digit `0` that we keep untouched must form a single `run` in the original string.

Therefore, if we denote:

- by $C_0$: the number of `0`s in the original string
- by $M_0$: the maximum length of a run of `0` in the original string

Then we need to perform the operation

- at least twice against each of the $C_0 - M_0$ `0`s, and
- at least once against each of the $N - C_1$ `1`s

This means the answer is at least:

$$2 (C_0 - M_0) + (N - C_1)$$
:::

```cpp
#include <bits/stdc++.h>

using namespace std;

void solve()
{
    int N;
    string S;
    cin >> N >> S;

    int cnt0 = 0, cnt1 = 0;
    for (auto c : S)
    {
        cnt0 += c == '0';
        cnt1 += c == '1';
    }

    vector<pair<char, int>> runs;
    for (int i = 0; i < N;)
    {
        int j = i;
        while (j < N && S[j] == S[i])
        {
            j++;
        }

        runs.emplace_back(make_pair(S[i], j - i));
        i = j;
    }

    int ans = 2 * N;
    for (auto [c, len] : runs)
    {
        if (c == '0')
        {
            ans = min(ans, N - len + cnt0 - len);
        }
        else
        {
            ans = min(ans, N - len + cnt1 - len);
        }
    }

    cout << ans << endl;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    while (t--)
    {
        solve();
    }

    return 0;
}
```

## 📌 E - Closest Moment{#E}

![426E]()

```cpp
#include <bits/stdc++.h>

using namespace std;

void solve()
{
    pair<double, double> ts, tg, as, ag;
    cin >> ts.first >> ts.second >> tg.first >> tg.second;
    cin >> as.first >> as.second >> ag.first >> ag.second;

    // a - b
    auto sub = [&](pair<double, double> a, pair<double, double> b) -> pair<double, double>
    {
        return {a.first - b.first, a.second - b.second};
    };

    // |a - b|
    auto dist = [&](pair<double, double> a, pair<double, double> b) -> double
    {
        pair<double, double> d = sub(a, b);
        return sqrt(d.first * d.first + d.second * d.second);
    };

    // a + (b - a) * p
    auto internal_division = [&](pair<double, double> a, pair<double, double> b, double p) -> pair<double, double>
    {
        double x = a.first + (b.first - a.first) * p;
        double y = a.second + (b.second - a.second) * p;
        return {x, y};
    };

    if (dist(ts, tg) < dist(as, ag))
    {
        swap(ts, as);
        swap(tg, ag);
    }

    pair<double, double> tm = internal_division(ts, tg, dist(as, ag) / dist(ts, tg));

    const int NUM_ITERATION = 60;

    // distance between the origin and segment AB
    auto dist_seg_and_point = [&](pair<double, double> a, pair<double, double> b) -> double
    {
        auto f = [&](double p)
        {
            return dist(internal_division(a, b, p), {0, 0});
        };

        double l = 0, r = 1;
        for (int i = 0; i < NUM_ITERATION; i++)
        {
            double ml = (l * 2 + r) / 3;
            double mr = (l + r * 2) / 3;

            if (f(ml) < f(mr))
            {
                r = mr;
            }
            else
            {
                l = ml;
            }
        }

        return f(l);
    };

    double d1 = dist_seg_and_point(sub(ts, as), sub(tm, ag));
    double d2 = dist_seg_and_point(sub(tm, ag), sub(tg, ag));

    cout << min(d1, d2) << endl;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    cout << fixed << setprecision(15);

    while (t--)
    {
        solve();
    }

    return 0;
}
```
